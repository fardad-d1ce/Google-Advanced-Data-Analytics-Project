## 🧠 About the Program

The **Google Advanced Data Analytics Certificate** is a rigorous, hands-on program that teaches advanced analytics skills required for data analyst and junior data scientist roles. Topics covered include:

- Exploratory data analysis
- Statistics and hypothesis testing
- Regression and classification models
- Data ethics and decision-making
- Machine learning foundations

---

## 🧰 Skills Gained

✔️ Data wrangling and preprocessing
✔️ Exploratory Data Analysis (EDA) using `pandas`,`matplotlib`, `seaborn`
✔️ Statistical testing and evaluation using `scipy.stats` 
✔️ Building and tuning ML models with `scikit-learn`  
✔️ Communicating insights and visualizations
